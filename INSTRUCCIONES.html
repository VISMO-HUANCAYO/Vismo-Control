VISMO · Control de asistencia

Aplicación instalable independiente de ChatGPT. Los archivos están preparados para GitHub Pages. Aún debes conectar la base de datos y crear las cuentas.

1. Crear la base de datos

  1. Entra a Supabase, crea tu cuenta y un proyecto. Conserva la contraseña de la base de datos.
  2. Abre SQL Editor, pega el contenido completo de backend.sql y ejecuta. Se ejecuta una sola vez, en un proyecto nuevo.
  3. En Authentication → Users → Add user, crea tu cuenta con tu correo y contraseña; confirma el correo desde esa opción.
  4. Ejecuta en SQL Editor la línea del final de backend.sql reemplazando TU-CORREO-AQUI con tu correo. Ese paso te da el rol de administración.
  5. Copia la URL del proyecto y su clave publicable o anon desde la configuración del proyecto. Completa config.js. Nunca pongas una clave service_role o secreta en la página.
  6. Desactiva el registro abierto de nuevos usuarios en las opciones de Authentication. Crea las cuentas de tus trabajadores desde Users, con una contraseña diferente para cada uno.

2. Publicar en GitHub

  1. Descomprime el ZIP. Crea un repositorio nuevo llamado vismo-asistencia.
  2. Sube los archivos de la carpeta directamente a la raíz del repositorio. No subas el ZIP. Puedes omitir los archivos fuente .tsx: app.js ya está compilado. No reemplaces tu web existente de VISMO.
  3. En Settings → Pages, selecciona Deploy from a branch → main → / (root) y guarda.
  4. Abre el enlace HTTPS que GitHub te entregue. Si aparece «Configuración pendiente», revisa config.js.

3. Preparar tu equipo

  1. Ingresa con tu cuenta administradora.
  2. En Obras y oficina, agrega cada centro. Puedes usar tu ubicación actual cuando estés allí. También puedes copiar latitud y longitud de Google Maps. Define un radio; 150 m es el valor inicial editable.
  3. En Trabajadores, agrega nombres, cargos y el mismo correo de las cuentas que creaste. Puedes agregar más personas, desactivarlas y reactivarlas; se conserva el historial.
  4. En Horarios, programa días y horas. Para el trabajador variable, programa sus cuatro fechas y el turno acordado. Los días sin turno no generan falta.
  5. Comparte el enlace de GitHub y entrega a cada trabajador su cuenta por un medio privado.

4. Instalar como app

En Android, abre el enlace en Chrome y busca «Instalar aplicación» o «Agregar a pantalla principal». En iPhone, abre en Safari → Compartir → Agregar a pantalla de inicio. La disponibilidad del botón depende del navegador.

Cómo funciona

  • Solo pide ubicación al marcar entrada o salida. No rastrea durante el día.
  • La hora de marcación se guarda en el servidor. Para detectar faltas y tardanzas, el panel compara el turno con esa hora; la vista se actualiza al volver a cargar.
  • Una llegada dentro de la tolerancia se considera puntual. Cuando hay tardanza, el reporte indica los minutos desde el inicio programado.
  • Rechaza ubicación fuera del radio o precisión peor que 100 m. Las coordenadas que envía un teléfono pueden falsearse; GPS no equivale a una huella biométrica.
  • Si no hay señal, no confirma una marcación. Administración puede registrar «Asistencia manual» con un motivo después. La app abre su interfaz sin conexión si ya fue instalada, pero necesita internet para datos y marcaciones.
  • Puedes corregir estados, justificar faltas o anotar minutos de una tardanza corregida. No modifica las marcaciones originales.
  • Reportes CSV para Excel por mes y centro. Un turno por trabajador y día; no incluye turnos nocturnos que cruzan medianoche ni múltiples entradas diarias.
  • Registra tanto entrada como salida del turno. No incluye cálculo de remuneraciones ni descuentos.
Antes de usarla oficialmente: prueba con una cuenta de trabajador real: ubicación dentro y fuera del radio, entrada y salida, cuenta desactivada y dos celulares. El paquete está compilado, pero la conexión, los permisos y el GPS deben comprobarse en tu proyecto. Necesitas conservar respaldos del proyecto; el reporte CSV no es una copia completa de la base de datos.
